# Digital Obscura

Сайт бродячего фотоаппарата: павильонная камера ФКП 18×24 со сканером Canon LiDE 210 вместо кассеты. Приглашённые фотографы снимают на неё серии, сайт собирает их вместе.

Сейчас это черновик: одна страница `index.html` без сборки и без сервера.

## Как открыть

- **На компьютере:** в папке сайта запустить `python3 -m http.server` и открыть http://localhost:8000. Если открыть `index.html` двойным щелчком, браузер может не загрузить шрифты.
- **Через GitHub Pages:** Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Через минуту-две сайт появится по адресу вида `https://<имя>.github.io/DigitalObscura/`.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Весь сайт: вёрстка, стили, тексты и данные о сериях |
| `img/` | Кадры: `ИМЯ.jpg` шириной 1800 px для страницы кадра, `ИМЯ_s.jpg` шириной 960 px для сеток |
| `fonts/` | Spectral (Light, Regular) и IBM Plex Mono (Regular), с лицензиями |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | Иконка «точка света» |

## Страницы

Адреса после `#`:

- `#home` — главная: случайная обложка и таблица серий;
- `#s03` — серия: контактный лист и текст к серии после сетки;
- `#s03-2` — кадр 2 серии 03; по нажатию раскрывается на весь экран, листается стрелками, свайпом и кнопками;
- `#izbrannoe`, `#izbrannoe-3` — избранное и кадр из него;
- `#camera` — «О проекте», `#meropriyatiya` — «Мероприятия», `#fotografam` — «Фотографам».

Вверху справа переключатель «День / Ночь»: светло-серая страница или графит. Выбор запоминается в браузере, по умолчанию день.

## Как добавить серию

1. Положить кадры в `img/`: большой (`ИМЯ.jpg`, ширина 1800 px) и маленький (`ИМЯ_s.jpg`, ширина 960 px).
2. В `index.html` найти `var SERIES = [` и добавить серию в начало списка:

```js
{id:'s04', author:'Имя Фамилия', n:'04', title:'Название серии', date:'05.12.2026',
  text:['Первый абзац текста к серии.', 'Второй абзац.'], textBy:'',
  shots:[
    {name:'Название кадра', f:'ИМЯ_ФАЙЛА', t:'19:40', alt:'Что видно на снимке'},
  ]},
```

- `text` и `textBy` можно не писать: тогда у серии нет текста и ссылки «Текст к серии».
- Если кадр не 1800×1476, добавить ему `w:` и `h:` (как у `shot01`).
- `alt` — описание снимка для тех, кто не видит экран.

3. Чтобы кадр попал в «Избранное», добавить его в `var FAVS` (номер серии и номер кадра с единицы). Обложки главной — `var COVERS` (номер кадра с нуля).

## Что здесь заглушки

- Названия серий и кадров, пробный текст к серии 03.
- Авторы: в таблице прочерки, в сериях «Автор не указан».
- Тексты страниц «О проекте», «Мероприятия», «Фотографам»; всё в квадратных скобках нужно заменить: почта, цена, сроки.
- Строка «Черновик…» в подвале страницы и запасная загрузка шрифтов с Google Fonts — убрать перед запуском.

## Права

- Снимки принадлежат их авторам. Использовать их без разрешения нельзя.
- Шрифты Spectral и IBM Plex Mono распространяются по лицензии SIL Open Font License 1.1, тексты лицензий лежат в `fonts/`.

## Выкладка на хостинг

Сайт работает на виртуальном хостинге Timeweb (тариф Optimo, «Основной сайт», папка `public_html`).

После любого изменения в ветке `main` GitHub сам заливает сайт на хостинг: файл `.github/workflows/deploy.yml`. Ход выкладки виден во вкладке Actions репозитория; там же её можно запустить вручную кнопкой Run workflow.

Для работы нужны три секрета в Settings → Secrets and variables → Actions: `FTP_HOST` (адрес сервера из блока «Доступ по FTP» в панели Timeweb), `FTP_USER` и `FTP_PASSWORD`. Выкладка только добавляет и обновляет файлы; удалённые из репозитория файлы на хостинге остаются, их убирают вручную в файловом менеджере.
